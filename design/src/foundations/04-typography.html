The admin reuses it for breadcrumbs, stat-card labels, table headers and button text, which is what ties the dashboard visually to the marketing site without borrowing any of its layout.

Numerals

Every number in a column is tabular

Non-tabular figures make currency columns ragged and KPI counters jitter as they update. This is the single highest-value typographic rule in an admin UI and the easiest to forget.
