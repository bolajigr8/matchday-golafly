Density

This is a dense tool, not a marketing page

matchday's existing button.tsx already defaults to h-8 (32px) with an h-6 extra-small — unusually tight for shadcn, and exactly right here. Someone reviewing 348 applications wants rows on screen, not air. The marketing site's rounded-[32px] cards and 72px section padding do not come across.

24 h-6 · xs Row-inline actions, dense filter chips
28 h-7 · sm Toolbar buttons, table-header controls
32 h-8 · default Everything by default — inputs, selects, buttons
36 h-9 · lg Sheet footer primary, empty-state CTA

32px is below the 44px touch target. That is a deliberate desktop-first trade — this dashboard is used at a desk. Anything that must work on a phone (the mobile drawer nav, the sheet close button) steps up to h-9 plus padding, and row actions get a larger invisible hit area than their visual box.

Spacing

A 4px base. Only these steps — no 5s, no 18s. Gaps inside a component come from the low end, gaps between components from the high end.

Radius

All derived from --radius: 0.625rem by the existing @theme block, so the whole product re-rounds from one value. Pills stay fully round — that is the shape the brand is already using everywhere.

Elevation

Depth comes from borders, not from stacked shadows. Only two things cast one: overlays, and the brand glow — which is an accent, not a depth cue.

border overlay glow

shadow-[0_0_12px_var(--brand-glow)] → hover 20px is the one interaction motif shared by every primary action in the app today. The admin keeps it, and uses it nowhere else — a glowing thing is always a thing you can click.
