{{icon:circle-help:14}} What proxy.ts can and cannot do

The guard is an optimistic cookie check, exactly as the two existing ones are: it stops the dashboard shell flashing before a client-side redirect. It cannot validate a token — only the Golafly API can — so a scout token is not prevented from reaching admin data here. It is prevented by the API returning 401, which the axios interceptor turns into a cleared session. Role-based access control (GOL-SCOUT-23) is a server concern; this screen is the courtesy.
