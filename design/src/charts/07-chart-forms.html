The only charts this dashboard needs

The Overview screen is the single place charts appear. Every one of them is a magnitude or a composition — no time-series forecasting, no scatter. Keeping the vocabulary this small is what stops an admin dashboard turning into a BI tool nobody maintains.

A funnel is just a sorted bar chart — do not draw a tapering trapezoid, which distorts area against value. Every stage is directly labelled with its count, and the drop-off between stages is the number people actually want, so it is stated rather than left to be worked out.

Bars are thin with a 4px rounded top and a square baseline — the rounding marks the data end, the flat end sits on zero. Gridlines are recessive and horizontal only. The y-axis starts at zero, always: a truncated axis on a count is a lie.

Never a second y-axis. Applications and approvals share a scale here because they are the same unit. Revenue against application count would be two charts, not two axes.

One series, so no legend — the label names it. No axes, no grid, no tooltip: a sparkline is a shape, not a chart you read values off. The end dot marks “now”. The delta beneath states the number, and carries an arrow so the direction is not colour-only.
