Everything here is built on the --sidebar-* tokens that were already defined and unused.

The lime bar is a fill; the label is type. That is why the 2px indicator can be raw --brand while the text beside it uses --brand-text. On a light sidebar the raw lime would be 1.16:1 as text — the bar gets away with it because a 2px block is not being read.

Active state is never colour-only: the wash, the bar and the weight change all move together, so it survives greyscale and forced-colors.
