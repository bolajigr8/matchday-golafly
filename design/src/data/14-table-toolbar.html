Active filters are visible, always

{{icon:search:14}} okonkwo Level U19{{icon:x:10}} Status Signed{{icon:x:10}} Nationality Nigeria, Ghana{{icon:x:10}}

Filters live in chips below the controls, never hidden behind a badge count. Each chip removes only itself; “Clear all” is separate and never the only way out. This is what makes the filtered-empty state recoverable — the cause is on screen next to the effect.

Each option carries its result count, so you can see a filter will empty the table before you apply it.

Selections apply immediately — no Apply button. The chip row above updates as you tick, which is the feedback that would otherwise need one.

Rows selected

{{icon:check:10}} 12 of 156 selected

The bulk bar replaces the toolbar in place rather than appearing above it — same height, same position, so the table never jumps when you tick a row. It states the selected count against the total, because “select all” on a paginated table is the classic footgun: 12 of 156, not just “12 selected”.
