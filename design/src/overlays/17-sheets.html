Form sheet · 440px. Wider than a detail sheet because it holds two-column date pairs, but never full width — the table behind it is the context you are creating into.

Sections use the same hairline captions as the detail sheet, so the two read as one family. The footer is sticky: on a long form the primary action never scrolls out of reach.

Validation is inline and adjacent — the failing field, then the message. No error summary at the top.
