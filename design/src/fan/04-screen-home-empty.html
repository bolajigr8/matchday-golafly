Why it looks like this

  • No zeroes anywhere. Not “0 tickets”, not “€0 spent”. A zero is a measurement; this fan has never bought anything, so there is nothing to measure.
  • No disabled shell. The greeting, the nav and the sections are all live — the dashboard is empty, not broken, and it should not feel like a locked door.
  • One action per slot. Three specific links beat one “Get started”, because the fan already knows which of the three they came for.
  • Distinct from the no-endpoint state. This says you haven’t bought anything. That one says we can’t read it back yet. Never the same screen.
