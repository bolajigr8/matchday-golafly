State

Status pills

Every domain status across all eight screens maps onto the five reserved tones. New statuses pick a tone; they never introduce a colour.

ToneMeansUsed for
ApprovedTerminal, successfulApproved · Active · Paid · Signed · Accepted · Published
PendingWaiting on a humanPending · Closing · Refunded · Awaiting review
Under reviewIn progress, no action neededUnder review · In progress · Scheduled
RejectedTerminal, failedRejected · Failed · Cancelled · Expired
DraftInertDraft · Inactive · Archived · Closed

Each pill is a tinted ground, a dot, and a text label. Colour is never the only carrier — the table stays readable in greyscale, in forced-colors, and to a colour-blind reviewer.

These five are also not the chart series colours. A green bar meaning “series 1” beside a green pill meaning “approved” is how a dashboard starts lying.

Toast for what just happened, alert for what is true. A toast is transient and reports the outcome of an action the user took; an alert is persistent and describes a condition of the thing on screen. Errors from the API include the failing call, same as the table error state — the people using this dashboard also run the backend.
